# 两分钟陪聊节拍与内部结论拦截

2026-11-06，沿用自主活动执行路线，在现有每日窗口中增加由真实交流驱动的两分钟机会。无需模型猜测“是否已经聊了两轮”。

## 行为与实现

- `companion_cadence.py`：唯一可空状态 `next_chat_due`。真人新消息（含转发）撤销旧计划并更新来源版本；真实发送取得消息 ID 后，设为完成时间加 120 秒。文字、贴纸、图片都计入；只有 reaction、未确认发送和失败发送不续排。到期领取先清空，正常安静结束便停止临时链。
- `runtime_policy.py` / `agent_loops.py`：旧候选在发送前核对最新来源及总开关，不能越过新消息或撤销指令。正常静默不关闭默认自由活动。旧 `silent_alarm purpose=chat` 创建／更新入口返回托管状态，不再改默认自由活动周期。
- `heartbeat/service.go` / `gateway/gateway.go`：每 5 秒轻量查询是否到期，未到期不调用模型；到期仍通过已有的真人会话状态、工作槽位和后台租约领取。接收审计中的旧 `received` 不能用于推断当前忙碌，避免合并输入留下的记录额外拖延唤醒。原分钟心跳保留。
- `fatfish_turn_event.go`：明确当前是自动陪聊机会，没有新的真人消息。上下文保留真实往来、记忆和少量续记；她可以聊天、阅读、探索、整理或做其他已授权的兴趣活动，允许安静结束。
- `internal_note_filter.py`：后台显式发送前检查正文、分条内容和媒体说明。诸如“这一轮不打扰他”“本轮保持静默”“这次不外发”的明确内部结论整批留内部，同回合停止后续工具派发，不通过改写重发。保留普通前台告别、引用及代码讨论。固定规则覆盖高置信度表达，不保证识别所有改写。
- `fatfish_exec_env.go` / `workspace-tools/emote_send.py`：通过单次进程环境传递来源，表情脚本也经过运行时发送票据和实际回执；被拦截不发送、不记为已用。保留原有挑图与 EMOTE-RULE 记账。

默认自由周期、任务巡检和额度守候继续各自运行。当前部署仍是 UTC+8 每天 18:00–22:00、默认每小时机会；两分钟链共用这个窗口和自主活动总开关。关闭后迟到回执不能重新续排。
